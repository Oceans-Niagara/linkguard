Deterministic link physics for transport code.

      

        LinkGuard is an offline-first Rust CLI, MCP server, and seeded packet proxy. It pairs local
        tree-sitter AST rules (Python, Rust, C/C++, TS/JS) with real physical-layer limits
        (lora-sf12, ble-1m, congested Wi-Fi, LEO satellite, UART) — zero LLM dependency, zero code leaving your machine.
      

      

        Open WASM Sandbox
        Pro & Team Keys
        Source on GitHub
      

    


    

      
Install & Run Locally

      
cargo install --git https://github.com/Oceans-Niagara/linkguard

linkguard analyze src/ --profile lora-sf12 --hz 10
linkguard check --config budgets.toml --format sarif
linkguard proxy --listen 127.0.0.1:9000 --target 127.0.0.1:9001 --profile ble-1m --seed 42
linkguard mcp
